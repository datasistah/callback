Sign in securely

under the hoodSupabase JWT · per-user Row-Level Security
2

Pick a goal — the agent takes over

The user chooses interview prep or resume rewrite. Both run on the same agentic engine, but each is grounded in a different source: the interview side reads the job description; the resume side reads the user's Career Vault.

Agentic engine

ReAct loop: reason → act → observe, looping until done. Interview prep works from the job description you paste; the resume rewriter calls vault_search to pull your real experience. Same engine, right source for each job.
