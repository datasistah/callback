Layer 5 · Embeddings

768-dim Vectors

rule: seed & serve with the same embedder

Deterministic signed-hash · deploy

Signed-hash embedder → 768-dim vectors. Free, reproducible, no external model.

Ollama nomic-embed-text · local

Local-only embedder → 768-dim vectors for development.

Layer 6 · Data

Supabase Postgres + pgvector

the Career Vault store

career_items

Vault rows with a 768-d embedding column.

HNSW index

Approximate-nearest-neighbour index over the embedding column for fast similarity.

match_career_items

RPC returning top-k similar vault items by vector distance.

RLS

Row-Level Security scopes every row per user — no cross-tenant leakage.

Agentic Flow — tracing one request

“Give me interview questions” → grounded, retrieval-augmented generation through the ReAct loop
Client → API User requests questions POST /api/interview with the target role / context.
Agent Harness ReAct loop starts Reason → decides to gather grounding first.
Tool · Data vault_search pgvector similarity via match_career_items → top-k items.
Tool · LLM question_gen LLM drafts questions grounded in the retrieved vault items.
Agent Harness Observe Validates tool output; loops again or proceeds.
Agent → API → Client Final Emits { final } → returns the response.
